# assets-src — исходники картинок и звуков

Здесь лежат **оригиналы** (большие PNG/JPG). На сайт они не попадают как есть — их режет скрипт.

## Как заменить заглушку на свою картинку

1. Откройте `README.md` в нужной папке — там список файлов, размер, что должно быть на картинке и готовый промпт.
2. Сгенерируйте картинку и положите её **с тем же именем** (например `products/sakura-65/01-main.png`).
3. Запустите:

   ```bash
   npm run images
   ```

   Скрипт сделает AVIF + WebP в нескольких ширинах, размытую заглушку и запишет всё в манифест.
   Сайт сам переключится со стокового фото на вашу картинку — код менять не нужно.

4. Закоммитьте `assets-src/…`, `public/img/…` и `src/shared/images/manifest.generated.json`.

Пока файла нет, показывается фото с Unsplash (бесплатная лицензия). Ссылки — в `src/shared/images/stock.ts`.

## Что уже готово

- `marketing/hero.jpg` — ваша сгенерированная главная картинка (уменьшена до 3840 px).
- `marketing/hero-mobile.jpg` — вертикальная версия, собрана скриптом из неё же.

## Папки

| Папка               | Что внутри                                      | Сколько |
| ------------------- | ----------------------------------------------- | ------- |
| `products/<товар>/` | Фото товаров, 4:5, единый студийный фон         | 82      |
| `marketing/`        | Hero, коллекции, дроп, клуб, мастерская, сетапы | 14      |
| `mascot/`           | Маскот «Кобо» в 7 позах, прозрачный фон         | 7       |
| `avatars/`          | Аватары для отзывов (сейчас — буквы в кружке)   | 8       |
| `sounds/`           | Звуки свитчей (сейчас — синтез Web Audio)       | 4       |
| `brand/`            | Логотип, иконки, OG-картинки                    | —       |

README в папках товаров/маркетинга/маскота генерируются командой `npm run images:readme`
(описания и промпты — в `scripts/image-briefs.ts`).
