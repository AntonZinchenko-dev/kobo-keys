# assets-src/sounds — звуки свитчей

Сейчас кнопка «Послушать звук» **синтезирует** звук прямо в браузере (Web Audio API,
`src/shared/lib/sound/switch-sound.ts`) — файлов не нужно, и это само по себе фишка для портфолио.

Если хотите настоящие записи:

| Файл                        | Звук                               |
| --------------------------- | ---------------------------------- |
| `switch-silk-linear.mp3`    | Мягкий глухой «тук»                |
| `switch-bamboo-tactile.mp3` | Чуть громче, с заметным «бугорком» |
| `switch-taiko-clicky.mp3`   | Звонкий щелчок                     |
| `switch-mochi-silent.mp3`   | Почти беззвучный                   |

Требования: 0,3–0,6 с, моно, до 30 КБ. Записать самому на любую механику или взять с лицензией CC0.
Положите файлы в `public/sounds/` и в `switch-sound.ts` замените синтез на `new Audio(...)`.
