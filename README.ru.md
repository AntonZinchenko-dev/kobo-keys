# KŌBŌ Keys — коротко по-русски

Портфолио-проект: интернет-магазин механических клавиатур. Бэкенда нет — его роль играет MSW прямо в браузере,
поэтому всё работает на GitHub Pages. Подробное описание для работодателя — в [README.md](./README.md).

Приложение начинается с экрана входа. Быстрее всего — кнопка **«Войти в демо-аккаунт»**;
можно и по-честному: любая почта, код `000000`. Тестовые карты и промокоды — в 🧪 панели разработчика.

## Запустить у себя

```bash
npm ci
npm run dev      # откроется http://localhost:5173/kobo-keys/
```

## Проверки перед коммитом

- `npm run check` — типы, ESLint, Stylelint, Prettier, архитектура FSD (Steiger), unit-тесты.
- `npm run test:e2e` — сборка + Playwright: покупка, отказ карты, 3-D Secure, фильтры, языки, доступность (axe), вёрстка на 360 px.
- `npm run size` — бюджет размера JS/CSS.

Перед каждым коммитом husky сам запускает линтеры на изменённых файлах и проверяет формат сообщения коммита
(`feat: …`, `fix: …` — conventional commits).
